# Buscador de películas

Aplicación web simple que busca películas según el input del usuario. 
- Muestra los resultados en una grilla responsive.
- Permite ordenar las películas por varios criterios.
- Actualiza los resultados automáticamente cuando el usuario escribe una nueva búsqueda.

> La aplicación consume la API de [ONDb](https://www.omdbapi.com).
